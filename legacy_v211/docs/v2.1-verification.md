- `scripts/run_offline_tests.py`는 실제 HTTP 연결을 차단하며 모의 응답이 없는 요청 시도도 집계해 1회라도 있으면 실패로 종료합니다.

- `python -m pip check`: `No broken requirements found.`
- 원본 v2의 소스 98개를 SHA256으로 다시 대조: 변경 0개. 새 폴더에 `.git`·가상환경·인증파일이 없는 것도 확인했습니다.
- `v2.1 실행.bat`를 실제 실행해 127.0.0.1:8504 서버 기동을 확인했습니다. Windows 실행 파일의 줄바꿈도 실제 실행 과정에서 수정·검증했습니다.

- 주 경로 성공·정상 재고 0·정상 빈 결과에서 보조 경로 생략.
- 명시적인 조회 불가와 빈 목록을 구분하고 오류·누락에 보조 경로 사용.
- 상품·점포 중복 제거, 원본 시각이 같거나 없을 때 충돌 자료 보류.
- 같은 조건의 동시 요청 공유와 사본 반환, 상품 코드·위치·모드·세션별 결과/오류 분리.

- 상품 후보·매장·재고 캐시 분리. 재고 강제 조회에서도 행사 브랜드 목록을 한 번만 수집.
- 앱 수신 시각과 원본 시각 구분, 원본 시각 미제공·과거 원본에 새 수신 시각이 붙어도 확정 재고로 승격하지 않음.
- 한국 시간 월말·날짜 경계·시작 전·기간 역전·만료 행사 차단. 미확인 연도·회원·카드·교차증정 조건 추정 금지.
- 브랜드 상품 코드와 공통 바코드 분리, GTIN 체크/패딩, 제조사·용량·맛·포장 충돌 거절.
- 사용자 확인 연결표의 저장·재사용·손상 파일 보존·동시 쓰기.
- 상품 사진 검색·장바구니 담기·수량 변경·삭제·예산·두 매장 비교·행사 수량·시연 대체 유지.

- 공개 원본 필드·경로별 오류를 보존하면서 인증 관련 키 제거. 요청 수·응답 시간·성공·실패·보조 사용 기록.

## 실제 외부 점검과 측정 범위

[재고 점검](v2.1-inventory-check.md)과 [행사 점검](v2.1-promotions-check.md)의 표·원자료를 기준으로 확인하세요. 자동 검사 성공은 실제 서비스 성공을 뜻하지 않습니다.

제한된 재고 실측은 브랜드별 1~3회, 합계 8회의 자료 요청과 별도 tools/list 1회입니다. CU·이마트24는 점포 재고를 반환했지만 원본 재고 시각이 없었습니다. GS25는 상품 검색만 성공했고 선택 재고는 실패했습니다. 세븐일레븐은 상품 검색에서 중계 오류가 관측됐습니다. 모든 원격 보조 경로의 정상 동작을 확인한 것은 아닙니다.

행사 공개 요청은 별도 문서에 실제 HTTP 호출과 자동 이동 수를 기록했습니다. GS25 새 공식 화면과 공개 스크립트에서 안정적인 행사 목록 계약은 확인하지 못했습니다. 공식 수집을 구현했다고 표시하지 않고 출처가 있는 제3자 참고 수단을 유지했습니다.

초기 전체 검사에서는 구형 모의 연결 두 건이 새 조회 진입점을 막지 못해 외부 요청 경로를 탈 수 있었습니다. 이 초기 검사 단계의 HTTP 시도 수는 별도 계측되지 않았습니다. 따라서 위 8회를 작업 전체의 모든 외부 요청 수라고 해석하면 안 됩니다. 모의 연결을 수정하고 최종 전체 검사에서는 외부 HTTP 차단과 미설정 모의 요청 0회를 확인하도록 강화했습니다.

모의 정상 조회에서 경로 작업 수 2개→주 경로 1개, 동일 동시 요청 6개→어댑터 1회, 유효 앱 캐시→원격 0회를 확인했습니다. 행사 수집의 이마트24 혜택별 5회→1회, CU 선행 화면 GET 2회→0회는 해당 코드 경로의 감소입니다. **동일 사용 조건의 v2 대비 전체 속도 개선율은 미측정**입니다. 단일 외부 응답 시간으로 평균이나 개선율을 주장하지 않습니다.

## 구현 범위와 남은 한계

- GS25 공식 상품 행사 자동 수집은 공개 계약을 확인하지 못해 구현하지 않았습니다. 출처를 표시한 제3자 참고 수집이 대체 동작입니다.
- CU·세븐일레븐의 키워드 결합 계약 때문에 후보 검색과 재고 요청을 완전히 분리할 수 없습니다. 선택명으로 좁힌 뒤 코드를 검증합니다.
- 중계 서비스의 자체 캐시·원본 갱신을 앱이 강제로 제어할 수 없습니다. 원본 시각 미제공·현재 점포 가격·행사 조건 부족은 확정 추천을 보류합니다.
- 제공되지 않은 행사 연도·조건은 보충하지 않습니다. 회원/카드/교차증정 가격 계산은 의도적으로 제외했습니다.
- LIVE 불안정을 TEST로 대체하지 않습니다. 부분·저장·상충·수량 미확인 자료는 확인 가능한 범위만 표시합니다.
- 새 대형 범용 프레임워크·AI API·유료 API·새 프런트엔드 의존성은 도입하지 않았습니다.
