# v2 검증 기록

검증일: 2026년 10월 31일 (한국 시간).

## 구현 범위

- 예산에 맞는 수량 조정: 유지할 상품은 고정하고, 줄이는 개수와 변경 상품 수를 최소화한다.
- 두 매장 구매: 상품 전체 수량을 최대 두 매장에 배정하고, 매장별 행사 비용과 직선 이동거리를 비교한다.
- 품절 대체: 명시적 분류·용량·단위·추가 금액과 확인된 재고 조건을 검사한다. 실시간 분류는 사용자 확인이 필요하다.
- 행사 수량: 1+1·2+1의 다음 묶음 수량, 추가 결제액과 재고를 확인한다.

## 회귀 검사

화면에서 조건을 바꾸어도 지난 추천을 그대로 적용하는 문제를 막기 위해 다음을 별도로 검사했다.

- 대체품을 담은 뒤 시연 장바구니를 다시 불러오면 상품 이름과 대응 코드가 함께 복원된다.
- 대체 후보 A를 확인한 뒤 후보 B, 용량, 단위를 바꾸면 해당 조합을 다시 확인해야 한다.
- 대체 검색에 포함된 원상품·후보의 별칭/충돌 관측을 버리지 않고 제안과 적용 시 모두 검사한다.
- 재고만 최신이고 가격·행사는 오래된 관측을 상단 확정 추천에서도 제외한다.
- 추천 표시 후 데이터의 유효 시간이 지나면 적용을 거절하고 이전 비교 결과를 지운다.
- 예산 입력을 비워도 오류로 종료하지 않고 입력 복구를 안내한다.

## 환경과 한계

Python 3.14.7 / Streamlit 1.65.0 / pandas 2.3.3 / requests 2.34.2 / Pillow 12.3.0.

실시간 화면 자동 검사는 모의 제공자를 사용했다. 이 기록은 모든 편의점·상품의 실제 연동 성공을 의미하지 않는다. 새 가상환경 재설치, 200% 실제 브라우저 확대, 스크린리더, 다른 브라우저 검증은 수행하지 않았다. 이동거리는 도보 경로나 소요 시간이 아니다. 공개 웹 배포는 하지 않았다.

원격 저장 시에는 `v2`의 파일 목록과 Git blob 해시를 로컬 스냅샷과 대조하고, `main`과 `v1-stable`이 원래 v1 커밋에 남아 있는지 확인한다.
