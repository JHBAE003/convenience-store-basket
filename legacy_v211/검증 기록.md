# 로컬 개발 검증 기록

검증일: 2026년 10월 31일

## 확인한 환경

Python 3.15.2, Streamlit 1.66.1, pandas 3.1.0, requests 2.34.2를 사용했다. 사용자의 기존 streamlit_env 환경이며 새 가상환경에서 재설치한 결과는 아니다.

## 구현과 점검

- 기존 코드 23개 모듈과 기존 테스트를 기말 과제 폴더로 옮겼다. 중간 과제 원본은 수정하지 않았다.
- 이식 직후 들여쓰기 안쪽의 import 두 곳을 수정했고, 기존 테스트 39개가 통과했다.
- 새 테스트를 추가하기 전에는 미구현 모듈 import로 실패하는 것을 확인한 뒤 기능을 작성했다.
- 시연 장바구니의 매장 총액은 A 5,300원, B 6,500원이고 예산 6,000원에서 A와 잔액 700원을 확인했다.
- 재고 부족·수량 미확인·가격 미확인·행사 미확인·중복 충돌·오래된 자료를 구분한다.
- AppTest에서 상품 추가와 삭제, 수량 변경에 따른 결과 무효화, 예산 재평가, 세션 분리, LIVE 전환과 모의 LIVE 선택·비교를 점검했다.
- 실제 브라우저에서 시연 장바구니와 추천 금액, 매장별 상태를 확인했다.
- 최종 `python -m unittest discover -s tests -q` 결과는 64개 통과, 실패·오류 0개였다. 화면 테스트의 MainThread ScriptRunContext 경고는 AppTest 실행 시 표시되는 진단이며 테스트 실패는 없었다.
- `python -m pip check`는 No broken requirements found, `python -m compileall -q core tests streamlit_app.py`는 오류 없이 종료했다.
- 로컬 서버의 `/_stcore/health`는 HTTP 200을 반환했다.

## 외부 조회의 제한적 점검

CU, 신라면소컵, 서울대학교 인근의 앱 기본 위치를 사용해 한 번 조회했다. 약 14.61초가 걸렸고 매장 관측 12건을 받았다. 상태는 LIVE였으며 표본의 판매가는 1,350원이고 정확한 재고 수량 필드가 있었다. 행사 조건은 미확인이었다.

이 점검은 해당 조회의 응답 확인이다. 다른 브랜드의 현재 연결 상태나 모든 상품의 수량·가격 정확성까지 검증한 것은 아니다. 행사 미확인 자료는 일반가 참고액으로 표시하고 확정 추천에는 사용하지 않는다.
