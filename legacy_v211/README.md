# 편의점 장바구니 v2.1.1

컴퓨팅 실습 기말 과제를 위한 Python·Streamlit 앱입니다. 상품 사진과 이름으로 상품을 찾아 장바구니에 담고, 가까운 편의점의 구매 가능 수량과 결제액을 비교합니다. v2의 예산 조정·두 매장 구매 비교·품절 대체·행사 수량 안내를 유지하면서 수집 요청과 정보 검증을 개선했습니다.

원본 `기말 과제 v2`·`기말 과제 v2.1` 폴더는 보존했습니다. 필요한 소스·자료만 복사한 독립 버전으로 `.git`, 가상환경, 임시 캐시, 로그, 개인 상품 연결표와 인증정보를 가져오지 않았습니다. 보안 업데이트는 GitHub `v2.1.1` 브랜치에 저장하며 기존 v2.1은 유지합니다. 공개 웹 배포는 하지 않습니다.

**2026-11-01 보안 업데이트:** 외부 상품 사진 주소가 내부망으로 연결되는 경로와 구매 목록 CSV의 수식 주입 경로를 수정했습니다. 두 경로는 외부 공급자 응답을 공격자가 조작할 수 있다는 전제가 있으며 낮은 심각도로 평가했습니다. 원본 비교·재현·수정 후 검증은 [v2.1.1 보안 변경 기록](docs/v2.1.1-security.md)에 있습니다.

- 사진은 확인한 호스트의 HTTPS·443과 공인 주소만 허용하며 실제 연결 주소를 고정합니다. 원래 호스트의 TLS 검증은 유지합니다. 새 이미지 호스트나 차단된 사진은 기존 대체 아이콘으로 표시합니다.
- CSV에서 수식으로 해석될 수 있는 문자열에는 **`[텍스트] `**를 붙입니다. 표의 내장 다운로드에도 적용하며 원본 상품·가격·수량은 바꾸지 않습니다.
- 오류의 인증정보 제거와 로컬 접속 설정을 보강했습니다. 후보 응답이 요청한 개수를 초과해도 최대 20개만 만들고 일부 확인으로 표시합니다.
- 설치된 직접·간접 의존성 35개의 정확 버전을 공식 OSV·PyPI 자료로 점검했습니다. 적용되는 알려진 자문은 반환되지 않았으며 새 취약점까지 없다는 뜻은 아닙니다. 기존 9강 실행 환경의 설치 패키지는 변경하지 않았습니다.

## 실행

**`v2.1.1 실행.bat`를 더블클릭**합니다. `로컬 실행.bat`도 같은 버전을 실행합니다. 브라우저 주소는 [http://127.0.0.1:8505](http://127.0.0.1:8505)입니다. 9강의 8501·v2의 8503·v2.1의 8504 포트와 분리했습니다. 종료는 실행 창에서 `Ctrl+C`입니다.

실행 파일은 이 폴더의 `.venv`, 기존 `streamlit_env`, 현재 `python` 순으로 환경을 찾습니다. 라이브러리가 없는 컴퓨터에서는 먼저 다음과 같이 설치하세요.

```powershell
cd "C:\Users\jhbae\Desktop\새 폴더\기말 과제 v2.1.1"
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run streamlit_app.py --server.address 127.0.0.1 --server.port 8505 --browser.gatherUsageStats false
```

검증 환경은 Python 3.15.2, Streamlit 1.66.1, pandas 3.1.0, requests 2.34.2, Pillow 13.0.0, urllib3 2.8.0입니다. urllib3는 기존 설치된 간접 의존성을 이미지 연결의 직접 의존성으로 명시했습니다. 다른 컴퓨터의 신규 설치까지 확인한 것은 아닙니다.

## 사용 순서

1. 저장 사진은 CU 상품입니다. **실시간 상품 검색**을 누르면 선택한 네 브랜드의 후보를 찾습니다. 첫 화면도 브랜드별로 섞어서 보여 줍니다. 목록 가격은 참고 판매가입니다.
2. 상품의 용량·맛·포장을 확인하고 담습니다. 여러 브랜드를 같은 상품으로 연결할 때는 직접 확인합니다. 공통 GTIN이 제공되고 규격 충돌이 없는 경우에는 그 근거를 사용합니다.
3. 주소·브랜드·반경·예산을 정하고 **매장 비교하기**를 누릅니다. 담은 상품의 코드를 기준으로 재고를 조회합니다.
4. **매장별로 받은 가격과 재고**에서 응답 수량·참고 가격·받은 시각을 확인합니다. 원본 시각·점포 가격·행사 조건이 부족하면 확정 구매 추천을 보류합니다. 다른 브랜드가 미연결이면 장바구니의 **다른 편의점 상품 연결**로 추가합니다. 반경 밖 점포도 표시하며 반경을 최대 20km로 넓힐 수 있습니다.
5. 예산·두 매장 비교·품절 대체·행사 수량 중 원하는 도우미를 선택합니다. 변경안은 적용 버튼을 눌러야 장바구니에 반영됩니다.

실시간 대체품도 후보 하나를 선택하고 종류·용량을 확인한 뒤 **선택 대체품 재고 확인**을 누릅니다. 후보 목록의 참고 가격을 구매 금액으로 사용하지 않습니다.

일부 브랜드가 실패하면 **실패한 브랜드만 다시 조회**로 복구합니다. 나머지 브랜드는 기존 자료와 시각을 유지합니다. CU·세븐일레븐의 큰 행사 목록은 재고 조회를 막지 않도록 분리했으며, 유효한 저장 자료가 없으면 **공식 행사 정보 추가 확인**을 눌렀을 때만 제한된 페이지를 수집합니다. 행사 미확인은 행사 없음이 아닙니다.

**시연용 데이터**에서는 기존 가상 상품·점포·가격을 유지합니다. **기능별 시연 → 상황 불러오기**로 네 가지 도우미를 확인할 수 있습니다. 기본 장바구니는 A점 5,300원, 두 매장 구매안은 4,900원입니다. 실제 판매 정보가 아닙니다.

## v2.1 주요 변경

### 필요한 경우에만 보조 조회

이전에는 같은 중계 서비스의 두 경로를 항상 동시에 실행했습니다. 현재는 브랜드별 계약에 맞춘 통합 MCP 호출을 주 경로로 사용하고, 오류·명확한 누락·해석 불가능한 응답에만 보조 경로를 사용합니다. 정상 재고 0과 정상 검색 결과 없음은 보조 요청 사유가 아닙니다. 수량 미확인·조회 실패와도 구분합니다.

MCP와 REST는 대부분 같은 `mcp.aka.page`를 사용하므로 독립된 두 출처라고 설명하지 않습니다. 이마트24 보조 조회에는 공개 공식 재고 API 직접 요청이 포함됩니다. 세븐일레븐 선택 재고는 중계 오류 시 공식 공개 API로 가까운 최대 3개 점포만 확인하고 부분 범위를 표시합니다. 지역 점포 목록은 출처·좌표별로 30분 재사용하며, 공식 보조는 최대 5 HTTP 요청(목록 캐시 시 4회), 자동 재시도 0회입니다. 기본 경로는 문서화된 상품 코드 계약과 기존 파서 재사용 가능성을 기준으로 선택했으며 속도가 더 빠르다는 가정은 하지 않았습니다.

동일 조건의 진행 중 요청을 공유하고 결과 사본을 반환합니다. 사용자별 관리자를 분리하고 상품 코드·키워드·정확한 좌표·모드·조회 종류별로 캐시와 오류를 구분합니다. 네트워크 재시도는 제한된 횟수만 허용하며 실패 직후 반복 클릭에도 짧은 대기 시간을 지킵니다.

### 상품 후보·매장·재고 캐시 분리

| 설정 | 기본 보관 시간 | 환경 변수 |
| --- | --- | --- |
| 재고 | 60초 | `CONVENIENCE_INVENTORY_CACHE_SECONDS` |
| 상품 후보 | 15분 | `CONVENIENCE_PRODUCT_CACHE_SECONDS` |
| 매장 | 30분 | `CONVENIENCE_STORE_CACHE_SECONDS` |
| 행사 | 6시간 | `CONVENIENCE_PROMOTION_TTL_SECONDS` |
| 재고 실패 후 대기 | 3초 | `CONVENIENCE_FAILURE_COOLDOWN_SECONDS` |

값은 초 단위이며 앱을 시작하기 전에 지정합니다. 재고 60초는 변동이 빠른 재고를 오래 재사용하지 않으면서 화면의 반복 실행 요청을 줄이기 위한 기본값입니다. 외부 서비스의 최신성 보장이나 서비스별 최적 TTL을 측정한 결과는 아닙니다. 매장·상품은 더 오래 재사용하되 후보 가격을 점포 가격으로 승격하지 않습니다.

GS25·이마트24는 선택 코드 조회를 지원합니다. GS25는 현재 서버 검증에 맞춰 코드와 상품명을 함께 보냅니다. CU·세븐일레븐의 중계는 키워드와 재고가 결합된 공개 계약의 제약이 있어 필요한 조회 후 정확한 코드로 검증합니다. 세븐일레븐 공식 직접 보조는 선택 코드 메타데이터를 사용합니다. CU 후보 검색의 일부 재고 요청을 완전히 없앴다고 주장하지 않습니다.

**앱에 저장된 재고를 사용하지 않고 다시 조회**는 이 앱의 저장 자료를 우회합니다. 중계·편의점 원본까지 강제 갱신됐다는 뜻은 아닙니다. 재고 재조회는 별도의 행사 캐시를 무효화하지 않습니다. 앱 수신 시각, 원본 자료 시각, 앱 저장 자료 사용 여부를 구분합니다. 원본이 제공하지 않은 시각은 만들지 않으며, 현재 재고의 확정 근거로도 사용하지 않습니다.

### 행사와 상품 연결 검증

CU·세븐일레븐·이마트24의 공식 수집기를 유지하고 중복 요청을 줄였습니다. GS25 기존 공식 주소는 새 JavaScript 사이트로 이동했습니다. 공개 화면·스크립트 확인 범위에서 안정적인 상품 행사 API를 확인하지 못해 **편의점행사.com**을 출처가 표시된 보조 참고 수단으로 유지합니다. 인증 우회나 비공개 앱 API를 사용하지 않습니다.

행사 기간·구매/증정 수량·회원/카드 조건·교차증정·출처·확인 시각을 제공 범위에서 저장합니다. 연도나 조건이 없으면 추정하지 않습니다. 종료된 행사는 캐시가 남아 있어도 한국 시간으로 다시 차단합니다. 일반 판매와 확인된 동일 상품 1+1·2+1만 계산하며 미검증 회원·카드·교차증정은 제외합니다. 수집 실패와 빈 결과도 행사 없음으로 확정하지 않습니다.

바코드와 브랜드 내부 코드는 별도입니다. GTIN이 없으면 제조사·전체 상품명·용량·맛·포장 수량을 보수적으로 비교합니다. 이름만 비슷한 다른 규격은 자동 연결하지 않습니다. 사용자가 확인한 연결은 기존 연결표 구조를 확장한 `user_data/confirmed_links.csv`에 저장해 이 컴퓨터에서 다시 사용합니다. AI·유료 API는 사용하지 않습니다.

최신 실제 화면 점검에서는 서울대 인근 펩시600ml 상품의 CU 6곳·GS25 2곳·이마트24 9곳·세븐일레븐 3곳 응답을 확인했습니다. 세븐일레븐은 중계가 502로 실패한 뒤 공식 직접 보조로 복구했고, 지역 목록 32곳 중 가까운 3곳만 확인했습니다. GS25 가격은 미제공이고 다른 브랜드의 2,500원은 참고 가격입니다. 원본 재고 시각과 점포별 현재 가격·행사 조건이 부족해 확정 추천은 보류합니다. 이 단일 품목·지역 관측은 전 상품·전 매장의 정상 동작이나 방문 시점 재고를 보장하지 않습니다. 앞선 실패 관측도 조사 문서에 남겼습니다.

요청 수 감소는 정상 재고의 이중 경로 2개→주 경로 1개, 이마트24 행사 혜택별 5회→키워드별 1회, CU 행사 선행 화면 GET 2회→0회에 한정합니다. 전체 사용 조건을 맞춘 v2 대비 속도 개선율은 **미측정**입니다. 단일 외부 응답 시간을 속도 개선율로 사용하지 않습니다.

매장 비교 상세의 **조회 점검 기록**에서 현재 세션의 최근 200개 상품·매장·재고 요청 기록을 보고 CSV로 저장할 수 있습니다. **조회 실패 원인 저장**은 공개 응답의 오류 상세를 별도로 저장합니다. 인증 관련 키를 제거하며, 요청 수 표에는 검색어·위치·인증정보를 넣지 않습니다. 행사·위치 검색·이미지 요청 수는 이 표에 포함되지 않습니다.

## 자료 기준과 이전 문서

실시간 장애를 시연 데이터로 대체하지 않습니다. 일부 성공·이전 저장·상충·수량 미확인 자료는 확정 추천에서 제외합니다. 사진 목록의 참고가를 현재 점포 가격으로 사용하지 않습니다. 두 매장 이동거리는 직선거리이며 도보 거리·시간이 아닙니다.

기존 Word 기획서·v2 검증 문서·개발 이력은 이전 버전 참고 자료로 보존했습니다. 현재 실행·동작은 이 README와 v2.1 문서를 기준으로 확인하세요. 원본 소스 98개 파일의 복사 전 SHA256은 `docs/v2-source-manifest.json`에 있습니다.
