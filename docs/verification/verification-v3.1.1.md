## 지도 다운로드

주변 도로망만 보관하며 표준 래스터 타일은 다운로드하지 않았습니다. Overpass의 POST/GET 요청 두 개는 502, 다른 공개 Overpass 요청 한 개는 읽기 시간 초과였습니다. 공식 OSM API에 전체 지역을 요청한 한 번은 50,000노드 제한으로 400을 받았습니다. 이후 작은 지역 **4개 요청이 모두 성공**해 합치고 도로와 그 참조 좌표만 추렸습니다. 총 시도 8회이며 재고 서비스의 LIVE 검증과는 별도입니다.

자료: 좌표 14,856개·길 3,043개·압축 366,423바이트. 해시·지역별 요청 URL·다운로드 시각은 `../../data/maps/metadata.json`에 있습니다. 전체 원본 갱신 시각은 미제공(null)입니다. 출처와 ODbL은 데이터 안내, 화면, SVG, GPX에 표시했습니다.

TEST의 출발지와 24개 매장 모두 연결됩니다. 출발지/매장 25지점 사이의 방향별 거리 600개가 유효했습니다. 매장 좌표에서 도로까지 연결 추정은 모두 30m 미만이었습니다. 이 확인은 실제 출입구나 현장 통행을 검증한 결과가 아닙니다.

## 코드 검토와 수정

범위를 제한한 독립 코드 검토에서 확인한 세 문제를 수정했습니다. 같은 도로 위치에 여러 지점을 삽입할 때 생기는 불필요한 우회, 완전히 같은 물리적 위치 사이의 진입 거리 중복, `access=permit` 길의 잘못된 허용입니다. 같은 위치·서로 다른 위치가 같은 도로 지점에 투영되는 경우·보행 일방통행 양쪽 방향의 회귀 검사를 보관했습니다. `foot=use_sidepath`도 직접 도로 보행에서 제외합니다. 수정에 대한 재검토에서 남은 구체적 결함은 보고되지 않았습니다.

최단 경로 탐색 트리는 전역 최대 8개, 좌표별 도로망은 최대 4개만 보관합니다. 각 도로망의 600개 거리 표를 재사용해 화면 조건 변경마다 전체 도로 탐색을 반복하지 않습니다.

원본 v3.1.0의 소스·자료 **206개**를 복사 전 해시와 다시 대조해 변경 없음을 확인했습니다. 기존 SQLite 자료도 유지했습니다. 현재 실행 파일은 `../../v3.1.1 실행.bat`, 포트는 8509입니다. GitHub 업로드와 Streamlit Cloud 배포는 수행하지 않았습니다.

남은 한계: 포함 지역 외 경로, 현재 폐쇄·신호 대기·조건부 통제·정확한 건물 진입 경로·접근성·실시간 길안내는 지원하거나 검증하지 않습니다. 지도 연결 실패 시 도보 추천을 제외하고 안내하며 직선 참고는 사용자가 직접 선택합니다. LIVE는 이번 검증 범위 밖입니다.
