# v3.2.1 구현·검증 기록

확인일: 2026-11-12. 로컬 구현입니다. GitHub 업로드·Streamlit Cloud 배포는 수행하지 않았습니다.

## 변경과 보존

원본 v3.2.0의 소스·자료 550개를 선별 복사했습니다. 가상환경·Git·캐시·로그·실제 인증키는 제외했습니다. 원본은 수정하지 않았으며 파일별 SHA-256을 [복사 시점 목록](../manifests/v3.2.0-preserved.json)과 비교했습니다.

새 버전의 엔진·TEST 공급자·데이터셋·기존 테스트·그림·OSM 원자료·공공자료 모듈 등 322개가 원본과 동일합니다. [보존 검사](v3.2.1-preservation.json). 지도 경로 계산·자료 해석·가격/재고 TTL은 변경하지 않았습니다.

화면은 기본 Streamlit 컨트롤을 유지하며 테마·카드 간격·그림 크기·검색 라벨·탐색 탭·추천 수치 위계를 정리했습니다. 작은 화면에서 장바구니가 숨겨져 비교 버튼도 사라지던 문제를 장바구니 이동/비교 영역으로 보완했습니다. 1024px에서 기존 좌우 배치의 장바구니 폭이 약 185px에 불과함을 확인하여 1280px 이하를 작은 화면 배치로 전환했습니다.

## 최적화

`planner/walk_map.py`의 결과 보관 범위를 지도망별 최대 8개로 제한했습니다. SVG/GPX 형식, 방문 순서, 왕복 조건으로 구분하며 지도망이 다르면 공유하지 않습니다. 잠금 안에서 완성된 문자열만 공유하고 실패한 결과는 저장하지 않습니다. 지도망 캐시는 기존 최대 4개 설정을 유지합니다. 좌표·도로 자료·도로 접근 추정·거리 산식은 그대로입니다.

로컬 Python 3.15.2, TEST 24개 점포, 같은 지도망에서 2곳을 같은 순서로 반복 출력한 결과입니다. 지도망/거리행렬 준비 후 첫 출력 1회와 반복 50회를 측정했습니다. 다른 검사와 동시에 실행되어 측정값에는 시스템 부하에 따른 변동이 포함됩니다.

| 측정 범위 | v3.2.0 | v3.2.1 |
|---|---:|---:|
| 반복 SVG 문자열 생성 중앙값 | 15.2735ms | 0.0008ms |
| 반복 GPX 문자열 생성 중앙값 | 0.02365ms | 0.0008ms |
| 해당 경로 첫 SVG 출력 1회 | 56.805ms | 70.8165ms |

첫 출력의 개선은 확인하지 못했습니다. 0.001ms 미만 수치는 타이머 해상도와 실행 환경의 영향을 받으며 앱 전체 속도 개선율을 뜻하지 않습니다. 재고·가격 외부 요청 수와 응답 속도, 첫 접속 시간은 미측정입니다. 방문 1/2/3곳 × 왕복 여부 × SVG/GPX의 **출력 12개가 바이트 단위로 동일**했습니다. [원자료](v3.2.1-performance.json).

검색 결과는 기존처럼 모든 브랜드 후보를 확인할 수 있습니다. 숨긴 브랜드 탭의 카드도 만들어지는 기존 구조는 유지하므로 매우 넓은 검색은 여전히 무거울 수 있습니다. 이번 버전에서 결과를 누락시키거나 페이지로 제한하지 않았습니다.

## 도구와 남은 한계

- Streamlit 개발 스킬과 설치된 1.66.1 참조 문서, Context7의 [공식 테마 문서](https://github.com/streamlit/docs/blob/main/content/develop/concepts/configuration/theming-colors-and-borders.md)를 사용했습니다. Design Partner 지침을 적용했습니다.
- 하위 에이전트로 성능 분석/구현, TEST 계약·추가 검사, 디자인 검토, 별도 회귀 검토를 분담하고 결과를 통합했습니다.
- Figma 도구는 확인했지만 대상 디자인 파일이 없고 직접 구현으로 충분하여 이번에는 Figma 파일을 만들지 않았습니다. Figma 시안이나 캡처를 제작했다고 주장하지 않습니다.
- 우선 브라우저 전용 스킬의 CLI를 확인했으나 설치되어 있지 않아 앱에 제공된 브라우저 도구로 화면을 확인했습니다.
- 실제 200% 확대는 시도한 단축키가 적용되지 않아 미확인입니다. 좁은 화면 검사는 확대 검사와 구분합니다. 스크린리더·고대비 모드·다른 브라우저·모든 입력 경계 대비는 검증하지 않았습니다.
- 실제 LIVE 재고/가격 조회, LIVE 모드 전환, 모의 LIVE 공급자 검사, 실제 공공 API 응답과 새 LIVE 화면은 검증하지 않았습니다. 기존 공공자료 키/승인 미설정 기록은 이번에 새로 확인하지 않았습니다.
- 공공 조사 가격을 확정 매장 가격으로 바꾸거나, 실시간 실패를 TEST 자료로 대체하지 않습니다. 앱 캐시를 건너뛰어도 원본 갱신은 보장하지 않습니다.
