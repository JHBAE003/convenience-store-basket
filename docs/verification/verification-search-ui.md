# 브랜드별 검색·요약 화면 변경

2026-11-05, v3.1.1 폴더에서 변경했습니다. v3.1.0 원본은 수정하지 않았습니다.

## 적용 내용

- 일반 담기에서 ‘장바구니에 담는 방법’과 ‘검색된 상품’ 선택 메뉴를 제거하고 상품 카드마다 **담기** 버튼을 제공합니다.
- 검색 결과를 CU·GS25·세븐일레븐·이마트24의 브랜드별 탭으로 표시합니다. 점포마다 같은 상품을 반복 나열하지 않습니다. TEST의 200개 후보 제한은 제거했습니다. 받은 검색 결과는 전부 표시하지만 외부 서비스가 반환하지 않은 상품까지 수집했다고 주장하지 않습니다.
- TEST에서 ‘우유’는 브랜드별 25종, ‘시연’은 브랜드별 300종을 반환합니다. 같은 가상 상품 ID·규격끼리 선택 브랜드를 자동 연결하고 서로 다른 용량·맛은 별개로 유지합니다.
- 이미 담은 상품은 표시를 바꾸고 중복 담기를 막습니다. 과거 수동 연결 선택이 일반 담기에 적용되지 않습니다. 기존 갤러리 담기도 같은 추가 함수를 사용합니다.
- 실제 상품의 다른 브랜드 수동 연결은 필요한 경우만 펼치는 **다른 브랜드의 같은 상품 연결 (선택)**에 남겼습니다. 규격 확인과 충돌 거절은 유지합니다. 새 검색에서 이전 확인 체크를 초기화합니다.
- **받은 자료와 확인 시각**은 처음에 접혀 있습니다. 기본 상품 3종은 기존 72개 점포별 행 대신 12개 브랜드·상품 행으로 요약합니다. 원본 시각 미제공·일부 미제공·여러 시각을 구분하며 가장 최근 시각 하나로 통합하지 않습니다.
- 가격·행사·재고도 브랜드·상품별 가격 범위, 확인 점포 수, 재고 있음·재고 0·수량 미확인 점포 수, 요청 수량을 살 수 있는 점포 수로 요약합니다. 재고를 합쳐 한 점포의 수량처럼 표시하거나 브랜드 전체에 같은 가격·행사가 적용된다고 표시하지 않습니다.
- 상단 TEST 출처 표는 4개 브랜드 행으로 줄였습니다. 점포별 관측·가격 계산·실제 방문 추천·지도·매장별 구매 목록은 그대로 유지합니다.

## 검증

`python scripts/run_test_mode.py`: **55개 TEST 검사 통과**, 외부 소켓 연결 시도 **0회**. 기존 TEST 47개에 검색 자료·브랜드 요약·UI 검사 8개를 추가했습니다. 최신 전체 결과는 `test-search-ui.log`입니다.

추가 검사는 모든 1,200개 브랜드별 후보와 300종의 가상 상품 유지, 용량·맛 분리, 브랜드별 탭과 직접 담기, 자동 연결, 이전 수동 설정과의 분리, 200개 제한 제거, 브랜드 조건 변경 시 이전 검색 숨김, 처음 접힌 확인 자료, 4행 출처·12행 비교 요약, 정상 재고 0·수량 미확인 구분, 종료 행사 할인 제외, 원본 시각 미제공·혼합을 확인합니다.

브라우저에서 `http://127.0.0.1:8509/`를 직접 열어 ‘우유’를 검색했습니다. CU·GS25·세븐일레븐·이마트24 각각 25종 표기, CU에서 GS25 탭으로 전환 후 25개 상품 이미지 표시, 일반 담기 방식 메뉴 제거, 확인 자료가 접힌 상태임을 확인했습니다. 화면 캡처는 `../screenshots/browser-brand-search.jpg`입니다.

사용자 지시에 따라 LIVE 모드 진입·LIVE 공급자 모의 실행·실제 외부 가격/재고 조회는 하지 않았습니다. LIVE용 기존 UI 테스트의 담기 버튼 선택 코드만 새 카드 키에 맞게 갱신했으며 실행하지 않았습니다. GitHub 업로드와 배포는 이번 변경에 포함하지 않았습니다.
