## 총거리 추천

기존 엔진은 이미 방향별 보행 거리행렬로 출발지부터 매장들을 방문하는 구간 합계와 왕복을 계산했습니다. 엔진을 재작성하지 않고 해당 동작을 유지했습니다. TEST 기본 기준은 가격·거리 균형이며 최저가/최단거리 모드도 선택할 수 있습니다. 구간 거리와 누적 거리를 화면에서 확인할 수 있고, 선택한 안과 최저가 안의 차이도 표시합니다.

새 기본 장바구니는 초코에몽250ml/가루비감자칩55g/동원샘물500ml 각1개입니다.

| 기준 | TEST 결제액 | 방문 | 총거리 |
|---|---:|---:|---:|
| 최저 결제액 | 4,400원 | 3곳 | 644m |
| 가격·거리 균형 | 4,600원 | 1곳 | 82m |

최저가 경로의 구간은 82m→152m→410m, 누적 82m→234m→644m입니다. 균형 안은 200원 더 내고 562m 덜 걷고 2곳 덜 방문합니다. 내부 계산은 반올림 전 거리를 사용합니다. 이 예시 가격/재고는 TEST이며 실제 구매 가능성 검증이 아닙니다.

반대 방향 순수 회귀 사례에서는 출발지에서88m인 B가159m인 C보다 가까워도 A+B 전체 경로는265m, A+C는159m입니다. 최저가 모드는 더 싼 A+B를 유지하고 최단/충분한 거리 부담을 적용한 균형 모드는 A+C를 선택합니다. [세부 점검](../research/real-test-v3.2.2/route-audit.md).
