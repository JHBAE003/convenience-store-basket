# 디자인 정리·검증 기록

2026-11-05, 기존 v3.1.1을 수정했습니다. Design Partner의 redesign 흐름과 설치된 Streamlit 1.66.1 문서를 적용했습니다.

## 적용한 구성

- 넓은 화면: 상품 목록 또는 추천·경로를 왼쪽에, 장바구니를 오른쪽에 둡니다. 수량·삭제·구매안 비교를 가까이 배치했습니다.
- 900px 이하: 상품 찾기·장바구니·추천·경로를 전환해 사용합니다. 상품 목록 뒤로 장바구니가 밀리지 않으며, 감춘 패널의 컨트롤은 화면·키보드 순서에서도 제외됩니다.
- 중복 제목, 반복되는 데이터 안내, 상시 캐시 설명, SQL/계산 구조 설명을 기본 화면에서 제거했습니다. 출처·자료 시각·상세 비교·지도 저장·조회 옵션·이동 조건은 접힌 보조 영역으로 옮겼습니다.
- 가상 데이터 표시·참고 가격·상품 구분용 그림·재고 미확인 구분·원본 시각 미제공·지도 추정 연결·실제 오류와 복구 안내는 유지했습니다.
- 상품별 삭제, 화면 사이 수량·검색어·분류·페이지·구매안 유지, 중복 증정 제안 정리를 추가했습니다. 추천 기준을 충족하지 못했을 때 다른 구매안이 있더라도 선택 기준의 실패를 먼저 안내합니다.
- 옅은 녹색 바탕, 흰 상품 면, 짙은 녹색 주요 동작, 일관된 제목·간격·테두리를 사용합니다. 개발자용 배포 메뉴는 Streamlit의 `client.toolbarMode="minimal"` 설정으로 감췄습니다.

## 참고한 공개 화면

- [컬리](https://www.kurly.com/main): 검색, 상품 이미지·상품명·가격·담기 순서와 정보 밀도.
- [Apple 지도](https://www.apple.com/kr/maps/): 주요 경로 정보를 먼저 보여주고 보조 설명을 분리하는 위계.

공개 페이지를 웹과 브라우저로 확인했습니다. 광고·대형 홍보 배너·브랜드 자산을 복제하지 않았습니다. 이미지·지도는 기존 로컬 파일을 사용하며 외부 폰트나 새 라이브러리를 추가하지 않았습니다.

## 자동 검사

`python scripts/run_test_mode.py` — **61개 통과**, 약 46.50초, 외부 소켓 연결 시도 **0회**. 최신 실행 로그: `test-design-ui.log`.

기존 TEST 55개를 유지하고 다음 6개 UI 검사를 추가했습니다.

1. 첫 화면의 상품·장바구니와 기술 설명 제거.
2. 비교 화면 이동 후 검색어·수량 유지 및 장바구니 화면 전환.
3. 상품 삭제 시 상품·연결·조회 결과 정리, 다시 담기.
4. 빈 검색·빈 장바구니·전체 상품으로 복귀.
5. 선택한 추천 기준 실패와 다른 구매안의 명확한 구분.
6. 상품 분류·페이지·명시적으로 고른 구매안의 화면 간 유지.

기존 추천·행사·분할 구매·지도·SQLite·브랜드별 검색/요약 검사도 포함됩니다. LIVE 모드·실제 재고/가격 조회·모의 LIVE 검사는 사용자 지시에 따라 실행하지 않았습니다.

## 브라우저 확인

- 기본 인앱 브라우저 1280×720: 상품/장바구니 배치, 구매안 비교, 기본 4,100원·도보 360m, 실제 경로 이미지, 접힌 자료 시각 확인.
- Chrome 320×900: 키보드 Enter 검색, 방향키로 CU→GS25 브랜드 탭 전환, 장바구니 수량 1→2 변경, 비교 후 추천·지도 표시 확인.
- Chrome 768×900: 추천 요약과 지도·화면 전환·패널 배치 확인.
- 320/768/1280 CSS px에서 문서의 가로 폭이 각각 320/768/1280px로 측정됐습니다. 장바구니 내부에도 가로 넘침이나 잘린 컨트롤을 발견하지 못했습니다. 표와 브랜드 탭의 국소 가로 스크롤은 허용합니다.
- 깨진 이미지 0개. Chrome에서 수집된 콘솔 오류 0개. 임시 화면 크기 설정은 원복하고 검증용 Chrome 탭은 닫았습니다.
- 인앱 브라우저에서는 화면 크기 설정이 실제 크기에 반영되지 않아, 크기 검증에만 지원되는 Chrome 도구를 사용했습니다.

스크린리더·터치 실기기·브라우저의 실제 200% 확대는 별도로 검증하지 않았습니다. 320px 재배치와 키보드 동작 확인을 접근성 인증으로 표현하지 않습니다. 새 모션은 추가하지 않았습니다.

설정한 주요 색 쌍의 계산 대비: 본문/바탕 11.47:1, 보조 글/바탕 5.49:1, 주요 버튼 흰 글/녹색 7.70:1, TEST 갈색 글/밝은 주황 바탕 6.03:1. 이는 지정 토큰의 정적 계산이며 전체 화면의 접근성 감사 결과가 아닙니다.

독립 코드 리뷰에서 발견한 선택 기준 실패 안내 누락과 화면 전환 시 선택 초기화 문제를 수정하고 회귀 검사·재검토를 마쳤습니다. 마지막 검토에서 남은 구체적 오류는 보고되지 않았습니다. 리뷰어는 LIVE와 시각 검증을 수행하지 않았고, 위 브라우저 확인은 구현 담당자가 수행했습니다.
