# 문서와 기록 안내

이 폴더는 실행 코드와 테스트를 건드리지 않고, 프로젝트 자료를 찾기 쉽게 분류합니다.

- `verification/`: 단계별 검증 설명, 자동 검사 결과와 로그
- `screenshots/`: 브라우저 화면 캡처와 경로 그림
- `manifests/`: 데이터·원본 파일 해시, 측정 조건 및 결과
- `research/`: 점포 조사 기록과 원자료
- `archive/`: 디자인 전 원본 백업

현재 앱 실행에 필요한 파일은 프로젝트 루트, `planner/`, `assets/`, `data/`, `.streamlit/`에 있습니다. `legacy_v211/`은 이전 버전 코드와 자료를 보존한 별도 폴더입니다.
