# 편의점 장바구니 v3.1.1

컴퓨팅 실습 기말 과제입니다. 장바구니를 편의점 1~3곳에서 나눠 살 때 결제액·거리·방문 수·예산을 비교합니다. v3.1.0의 공통 TEST/LIVE 화면에 **상품별 간단한 그림**과 **다운로드한 실제 도로 지도·도보 경로**를 추가했습니다.

## 실행

Windows에서 **`v3.1.1 실행.bat`**를 두 번 클릭합니다. 이 버전은 <http://127.0.0.1:8509/>를 사용합니다. 같은 주소에 앱이 이미 실행 중이면 실행 중인 창을 이용하세요. 기존 v3.1.0 폴더와 8508 포트는 보존했습니다.

터미널에서 직접 실행할 수도 있습니다.

```powershell
cd "C:\Users\jhbae\Desktop\새 폴더\과제물\기말과제 프로젝트\버전별\기말 과제 v3.1.1"
python -m pip install -r requirements.txt
python -m streamlit run streamlit_app.py --server.address 127.0.0.1 --server.port 8509 --browser.gatherUsageStats false
```

실행 파일은 프로젝트의 `.venv`, 기존 `streamlit_env`, 기본 `python` 순으로 사용할 수 있는 실행기를 고릅니다. 새 가상환경이나 API 키는 포함하지 않았습니다.

## 간소화한 화면

**상품 찾기 → 장바구니 → 추천·경로**로 이동합니다. 넓은 화면에서는 상품 목록과 장바구니를 함께 보여주고, 900px 이하에서는 각 화면을 따로 보여줘 검색과 수량 조절을 바로 사용할 수 있습니다. 상품 분류·목록 페이지·검색어·선택한 구매안·장바구니 수량은 화면을 오가도 유지합니다.

**구매안 비교**를 누르면 선택한 상품의 가격·재고를 확인하고 추천·경로 화면을 엽니다. 개별 상품 삭제와 전체 비우기를 지원합니다. 상세 비교표, 증정 제안, 확인 시각, 지도 저장은 추천 화면에서 필요할 때 펼칩니다. 조회 옵션과 이동·세부 조건도 접힌 영역으로 옮겼습니다. 알고리즘·캐시·파일 형식 설명은 기본 화면에서 제거했습니다.

Design Partner 플러그인으로 [컬리](https://www.kurly.com/main)의 상품 정보·담기 구성과 [Apple 지도](https://www.apple.com/kr/maps/)의 경로 정보 위계를 참고했습니다. 기존 로컬 그림·지도와 Streamlit 기본 컨트롤을 사용하며 외부 디자인 자산·폰트·새 라이브러리를 추가하지 않았습니다.

## 상품 그림

- 가상 상품 **300종 각각**에 작은 SVG 그림이 있습니다. 분류별 포장 형태, 맛별 색, 용량·포장 수·상품 코드를 표시합니다. 실제 포장 사진이 아닙니다.
- 첫 화면에서 상품을 분류별로 12종씩 둘러보고 바로 담을 수 있습니다. 검색 결과와 장바구니에서도 같은 그림을 사용합니다. 검색된 상품에는 페이지 제한을 적용하지 않습니다.
- 실제 상품에 대응하는 그림이 없으면 공통 그림을 사용합니다. 원격 이미지 서비스나 유료 API를 호출하지 않습니다.
- 그림은 사진·가격·재고 확인의 근거로 사용하지 않습니다. 다른 규격은 별도 상품으로 유지합니다.

그림은 `assets/product_icons/`에 있으며 `python scripts/build_product_icons.py`로 같은 데이터에서 재생성할 수 있습니다.

## 실제 도로 지도와 경로

OpenStreetMap의 서울대입구역 주변 도로·보행로를 한 번 내려받아 **압축 JSON 벡터 자료**로 포함했습니다. 좌표 14,856개, 길 3,043개이며 지도 파일은 약 366KB입니다. 지도와 상품 그림을 합쳐 약 607KB입니다. 실행 중 지도 타일이나 경로 서버에 요청하지 않습니다.

- TEST 기본 거리 계산은 **도보 경로**입니다. 내려받은 도로망의 최단 경로를 계산하고 1~3곳의 방문 순열을 비교합니다. 최단 이동·예산·균형 추천과 거리 상한에도 같은 거리를 사용합니다. 출발지로 돌아오는 경로도 지원합니다.
- 지도에는 실제 거리 모양과 도로명이 표시됩니다. **초록 실선**은 도로 경로, **황토 점선**은 점포 위치에서 가까운 보행로까지의 추정 연결입니다. 합계 거리에는 연결 추정이 포함됩니다.
- 반경 필터는 여전히 출발지 기준 **직선 반경**입니다. 전체 이동거리 상한과 구분합니다.
- 지도와 도로 경로를 SVG·GPX로 저장할 수 있습니다. GPX에는 도로 구간만 담고 미확인 진입 연결은 제외합니다. 화면 합계와 GPX 도로 길이는 이 때문에 다를 수 있습니다.
- 지도 범위는 남37.465~북37.495, 서126.926~동126.975입니다. 범위 밖이거나 120m 이내 보행로를 찾지 못하거나 길이 연결되지 않으면 해당 경로를 계산하지 않습니다. **직선으로 자동 대체하지 않습니다.** 필요하면 사이드바에서 **직선 거리(참고)**를 직접 선택합니다.

지도에 기록된 보행 불가·사유지·허가 필요 길을 제외하고 보행 일방통행을 반영합니다. 건물 출입구, 신호 대기, 조건부 통제, 공사·폐점의 현재 상태와 접근성은 검증하지 않았습니다. 점선 연결은 벽이나 도로를 실제로 통과할 수 있다는 뜻이 아닙니다. 이 앱의 경로는 다운로드한 범위 안에서의 도보 참고안이며 실시간 내비게이션이 아닙니다.

지도 자료는 [© OpenStreetMap contributors](https://www.openstreetmap.org/copyright), ODbL 1.0입니다. [자료·이용 조건](../data/maps/LICENSE.md)과 [다운로드 기록](../data/maps/metadata.json)을 확인하세요. 래스터 타일의 일괄 다운로드는 하지 않았습니다.

지도 재다운로드는 앱 실행과 분리한 `scripts/download_walk_map.py`에서만 가능합니다. 기존 지도는 덮어쓰지 않으며 이번 작업에 사용한 공식 OSM API의 작은 영역 4개 요청을 재현합니다. 원본 전체 갱신 시각은 미제공으로 보존합니다.

## 데이터와 기본 사용 흐름

TEST는 서울대입구역 근처 실제 점포명·위치 24곳(브랜드별 6곳), 가상 상품 300종, 점포별 판매 자료 7,200행을 읽기 전용 SQLite에서 사용합니다. 상품·가격·행사·재고는 모두 가상이며 현재 영업 여부를 보장하지 않습니다. 행사 기준일은 2026-11-15 고정입니다. [점포 조사 기록](../docs/research/store-research.md)을 포함했습니다.

상품 검색/그림 목록 → 장바구니 수량 설정 → **구매안 비교** → 추천 기준·예산·거리 조건 비교 순서로 사용합니다. 검색 결과는 **브랜드별 탭의 상품 카드**로 전부 표시합니다. 점포마다 같은 상품을 반복해서 나열하지 않습니다. TEST의 기존 200개 후보 제한도 제거했습니다. ‘우유’ 검색은 브랜드별 25종이며, ‘시연’ 검색은 브랜드별 300종입니다.

일반 상품은 카드의 **담기** 버튼 하나로 추가합니다. ‘장바구니에 담는 방법’ 메뉴는 제거했습니다. TEST의 동일 가상 상품은 선택한 브랜드끼리 자동 연결합니다. 실제 상품에서 다른 브랜드 후보를 수동 연결할 필요가 있을 때는 접힌 **다른 브랜드의 같은 상품 연결 (선택)**에서 규격 확인 후 연결할 수 있습니다. 일반 담기에 이 선택을 적용하지 않습니다.

추천·경로 화면의 **받은 자료와 확인 시각**은 처음에 접혀 있습니다. 열면 브랜드·상품별로 요약한 확인 점포 수·수신 시각·원본 시각·캐시 정보를 표시합니다. 서로 다른 시각을 최신 시각 하나로 바꾸지 않으며 미제공도 구분합니다. 가격·행사·재고 비교도 브랜드별 가격 범위와 재고 있음/0/수량 미확인 점포 수로 요약합니다. 실제 방문할 점포는 추천·지도·매장별 구매 목록에서 확인합니다. 점포별 원자료와 계산은 내부에서 그대로 유지합니다.

최대 상품 6종·각 12개·매장 24곳·방문 3곳을 지원합니다. 수량은 증정분을 포함해 받을 개수입니다. 추가 증정 제안은 사용자가 적용해야 장바구니가 바뀝니다.

기본 상품 3종의 가상 최저 결제액은 **4,100원**, 방문은 세븐일레븐 서울대제일점 → GS25 봉천메트로점입니다. 이번 지도에서 이동거리는 연결 추정 포함 약 **360m**, 직선 참고 거리는 약 248m입니다.

LIVE 공급자·기존 수집 코드는 보존했습니다. 모드 전환 시 상품·조회 자료·임시 상태를 초기화하며 실제 조회 실패를 TEST로 대체하지 않습니다. 참고 가격, 정확한 수량 미확인 재고, 만료된 조회는 확정 구매안에 사용하지 않습니다. LIVE의 기본 위치인 서울시청은 포함된 지도 밖이므로 직선 참고가 기본이며, 지도 이용을 위해서는 포함된 지역의 위치가 필요합니다. **사용자 요청에 따라 이번 작업에서는 LIVE 모드·실제 가격/재고를 검증하지 않았습니다.**

## 검증

```powershell
python scripts/run_test_mode.py
```

이 명령은 TEST 엔진·SQLite·화면·그림·지도만 검사합니다. 외부 소켓 연결을 차단하며 LIVE 공급자 테스트와 LIVE 전환 테스트, 기존 수집 코드 테스트는 실행하지 않습니다.

최신 디자인 변경의 검증은 [화면 검증 기록](../docs/verification/verification-design.md)과 [61개 TEST 검사 로그](../../기말%20과제%20v3.1.1/docs/verification/test-design-ui.log)에 있습니다. 이전 단계의 기록은 [브랜드별 검색·요약 검증](../docs/verification/verification-search-ui.md), [최초 v3.1.1 검증](../docs/verification/verification-v3.1.1.md), [측정 조건·결과](../docs/manifests/measurement-v3.1.1.json)에 보존했습니다.
