# v3.1.0 TEST 데이터 확장 검증 기록

검증일: 2026-11-05 (한국 시간). Python 3.15.2 / Streamlit 1.66.1 / streamlit_env 사용.

## 검증 범위

서울대입구역 주변 실제 점포 이름·좌표를 이용한 고정 SQLite TEST 자료와, 그 자료를 검색하고 추천하는 기능을 확인했습니다. 8가지 상황 선택 UI는 제거했습니다. 기존 시나리오 자료는 엔진 단위 검사에만 남아 있으며 실행 화면에서는 가져오지 않습니다.

외부 실제 가격·재고 조회는 이번 작업에서 실행하지 않았습니다. 점포 조사는 매장명·주소·좌표를 확인하는 일회성 공개 매장/인허가 조회였습니다. 사용자가 LIVE 검증 중단을 요청한 이후 추가 LIVE 검증은 실행하지 않았습니다.

## 데이터 파일

- data/test_dataset.sqlite3: 872,448바이트, 읽기 전용으로 사용.
- stores 24행, 브랜드 4종 각각 6곳, 모두 역 중심 참고점에서 직선 2km 이내.
- products 300행, 12개 분류 각각 25종의 가상 상품.
- brand_products 1,200행: 브랜드 내부 가상 상품 코드를 별도 보존. 실제 GTIN을 발급하거나 추정하지 않음.
- offers 7,200행: 모든 점포에 정확히 300종. 가격·행사·재고는 전부 가상.
- source 원장/조사 기록: data/store_sources.json, docs/store-research.md.
- 데이터 파일 SHA-256 및 개수: docs/dataset-manifest.json.

모드 간 격리와 모의 LIVE 응답을 이용한 기존 회귀 검사도 사용자의 중단 요청 전에 완료했습니다. 이 결과로 외부 LIVE 가격·재고가 현재 동작한다고 주장하지 않습니다.

계산 엔진은 24개 점포를 모두 고려하며 최대 3곳을 방문합니다. 동일 상품·수량의 결제액을 미리 계산하고, 한 품목의 같은 사용 점포 집합에서 최소 비용 배분을 보존해 반복 계산을 줄였습니다. 기존 8개 계산 사례 및 36개 작은 무작위 사례의 독립 완전 열거 대조가 통과했습니다. 임의로 가까운 12곳만 잘라 계산하지 않습니다.

기본 상품 3종·각 1개에서는 각 품목별 확인 재고가 있는 최소 단가의 합이 4,100원임을 SQLite에서 별도로 계산했고, 추천도 동일했습니다. 매장 조합 24+276+2,024=2,324개를 모두 검사했습니다.

## 브라우저 TEST 확인

기존 실행 서버가 수정 전 모듈을 유지하는 현상을 확인해 서버를 재시작했습니다. 새 프로세스의 localhost:8508에서 다음을 확인했습니다.

- 8가지 상황 버튼이 없어지고 24곳·점포당 300종·총 7,200건 안내가 표시됨.
- 기본 장바구니는 실제 점포 이름을 쓰는 4,100원 추천을 생성함.
- 김치 컵라면 65g을 검색하고 담으면 4개 브랜드가 같은 합성 상품 ID로 연결됨.
- 가격·재고 확인을 누르면 기존 3종+컵라면의 4개 품목에 대해 3곳 방문, 5,000원 구매안이 계산됨.
- 추가 상품을 담기 전에는 이전 구매안을 새 조건의 추천으로 표시하지 않음.
- 사용자 LIVE 검증 중단 요청 후에는 TEST 화면만 확인하고 기본 TEST 장바구니로 남김.

화면 증거: browser-test-dataset.jpg. 기존 browser-test.jpg / browser-live.jpg는 최초 v3.1.0 구현 당시의 이전 화면 자료로 이번 데이터 확장의 증거로 사용하지 않습니다.

## 측정 조건과 한계

단일 로컬 실행 측정, 외부 HTTP 없음, 24개 점포·반경 2km·최대 방문 3곳·전체 직선 이동 상한 20km·복귀 없음·예산 엄격 적용 없음. 데이터 읽기는 계산 시간에 포함하지 않고 solve 함수만 측정했습니다.

| 상품 조건 | 검사한 매장 조합 | 계산 시간 | 가상 최저 결제액 |
|---|---:|---:|---:|
| 기본 상품 3종×각 1개 | 2,324 | 0.2744초 | 4,100원 |
| 지정 상품 6종×각 12개 | 2,324 | 2.2861초 | 73,100원 |

정확한 상품 ID와 조건은 dataset-measurement.json에 있습니다. 다른 작업이 함께 실행 중이었던 1회 측정으로 UI 전체 응답 시간이나 반복 평균, 변경 전후 성능 향상 비율을 뜻하지 않습니다.

점포명과 위치의 공개자료 등재만 조사했습니다. 현재 현장 영업 여부, 실제 취급 상품·가격·행사·재고는 검증하지 않았습니다. 특히 CU는 공식 중계 실패 후 공개 인허가 자료 재게시 목록을 사용했으며, 원본 자료가 조사일에 갱신됐다고 가정하지 않습니다. 이마트24는 다른 브랜드보다 멀리 분포하여 약 1.85km 점포까지 포함합니다.
