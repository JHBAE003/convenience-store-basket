# 총 도보거리와 방문 순서 점검

확인일: 2026-11-12. TEST/로컬 지도만 검사했습니다. LIVE 재고·가격·공급자·전환 검사는 수행하지 않았습니다.

## 확인한 기존 동작

`planner/engine.py`의 `route_for`는 선택한 매장의 방문 순서를 모두 비교하고 `출발지 → 첫 매장 → 다음 매장`의 **구간 거리 합계**를 최소화합니다. 왕복을 선택하면 마지막 매장에서 출발지로 돌아가는 구간도 합산하고 방문 순서를 다시 고릅니다. 따라서 출발지와 각 매장 사이 거리만 더하는 계산이 아닙니다.

화면에서 도보 경로를 선택하면 `planner/walk_map.py`가 만드는 방향별 보행 거리행렬이 엔진에 전달됩니다. 출발지 반경은 후보 매장 필터이고, 전체 이동거리 상한은 별도로 실제 방문 경로 합계에 적용됩니다. 기존 엔진과 지도 계산이 요구사항에 맞아 이 점검에서는 두 파일을 재작성하지 않았습니다.

추천 기준도 구분합니다. **최저 결제액**은 결제액을 우선하여 멀어도 더 저렴한 안을 고를 수 있습니다. **최단 이동**은 전체 이동거리 우선이며, **가격·거리 균형**은 `상품 결제액 + 총 도보거리 × 거리 부담값 + 추가 방문 부담값`을 비교합니다. 부담값은 비교 점수로서 실제 교통비가 아닙니다.

## 실제 지도 근거

- 보존된 OSM 자료: `data/maps/seoul_walk.osm.json.gz`, 14,856개 노드, 3,043개 도로/보행로, 압축 366,423바이트.
- 지역: 위도37.465~37.495, 경도126.926~126.975. 서울대입구역 주변을 포함합니다.
- 내려받은 시각: **2026-11-05T11:07:50.739483+00:00**. 원본 갱신 시각은 메타데이터에 **미제공**이며 새 시각으로 만들지 않았습니다.
- 원본 endpoint: `https://api.openstreetmap.org/api/0.6/map.json`, 실제 요청의 bbox 네 개와 SHA-256은 `data/maps/metadata.json`에 남아 있습니다.
- [OSM API 문서](https://wiki.openstreetmap.org/wiki/API_v0.6)는 bbox로 원시 지도 요소를 조회하는 계약을 안내합니다. [보행 일방통행 문서](https://wiki.openstreetmap.org/wiki/Key:oneway:foot)는 보행 방향 제한을 구분합니다. [OSM 출처·라이선스](https://www.openstreetmap.org/copyright)는 지도 자료의 ODbL 및 기여자 표시를 설명합니다. 세 페이지를 이번 점검에서 공개 웹으로 열어 확인했습니다.
- 런타임은 네트워크로 새 지도를 요청하지 않고 파일을 읽습니다. 현장 보행 가능 여부, 최신 공사/출입구/점포 입구는 검증되지 않았습니다. 점포 좌표에서 보행로까지의 점선은 추정 연결이며 총 거리에 포함됩니다. 범위 밖/연결 불가 시 직선 거리로 몰래 대체하지 않습니다.

## 추가 검사와 판정

`tests/test_route_total.py`에 반대 방향 우회, 가격/거리/균형 기준 차이, 전체 경로 상한, 3곳 방문 순서와 왕복 재선택, 실제 지도 경로 합계를 검사하는 6개 회귀 검사를 추가했습니다. 다음이 핵심 사례입니다.

- 동쪽 필수 매장 A, 서쪽 저렴한 매장 B, 동쪽 대체 매장 C가 있습니다. B는 C보다 출발지에 가까워도 A+B 총 동선은 A+C보다 깁니다.
- 가격 우선은1,900원인 A+B를 유지하지만, 최단 이동과 충분한 거리 부담값을 적용한 균형 추천은2,100원인 A+C를 고릅니다. 모든 추천 모드가 무조건 가까운 매장을 고르도록 바꾸지는 않습니다.
- 개별 매장 B는100m 이내여도 전체200m 상한에서는 A+B를 제외합니다.
- 방향별 거리가 다른3곳 사례는 편도와 왕복의 최적 순서가 달라지는 것을 확인합니다.
- 실제 저장 지도에서도3곳의 모든6개 방문 순서와 편도/왕복을 비교하여 선택한 총 거리와 지도 구간들의 합계가 일치하는지 확인합니다.

실행 결과: Python3.15.2에서 명시적으로 이 테스트 모듈만 골라 기존 소켓 차단 장치 아래 **6개 성공(0.330초), 외부 연결 시도0회, 실패/오류0개**였습니다. `planner/engine.py`와 `planner/walk_map.py`는 v3.2.1과 SHA-256 비교로 동일함을 확인했습니다. 새 실측 거리·실제 보행 시간이나 최신 점포 출입구를 확인했다고 해석하면 안 됩니다.
