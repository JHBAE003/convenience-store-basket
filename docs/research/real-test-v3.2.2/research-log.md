## 실패 경로·전환과 한계

- GS25 공식 주소는 JavaScript 화면으로 이동하여 이번의 신뢰 가능한 상품 수집원으로 완료하지 못했습니다. 공개 보조 목록을 사용했습니다. 보조 목록의 스크롤 요청이 403을 반환하자 중단하고 공개 검색 화면만 사용했습니다(E2). 로그인/차단 우회는 하지 않았습니다.
- CU/세븐일레븐의 공개 화면은 목록을 별도 공개 요청으로 채웁니다. 페이지 URL과 실제 수집 요청은 원자료에서 구분했습니다(E1,E2). 공식 화면의 조기 품절/일부 점포 제외 안내를 현재 점포 재고로 해석하지 않았습니다.
- 독립 검토자가 이마트24 원문을 새로 여는 시도는 웹 도구에서 실패했습니다. 앞서 수집기가 받은 응답과 추적은 보존하되 이를 모든 원문의 재검증 성공으로 표현하지 않았습니다. [독립 검토](independent-verdict.md).
- 공급자 접두사만으로 제조사라고 단정하지 않았습니다. 제품 사진 파일 이름의 숫자를 GTIN으로 바꾸지 않았습니다. 상품별 실제 행사 기간·회원/카드/교차 조건은 미확인입니다(E1–E3).
- 기간 미제공 행사에는 TEST 날짜와 동일 상품 증정 가정을 별도 필드로 사용합니다. 이 가정은 원본 확인값이 아닙니다. 1개 수량은 해당 목록 단품/묶음 1개를 뜻하므로 20입 상품을 물 1병으로 취급하지 않습니다(E3,E5).
- 지도 내려받은 시각은 2026-11-05이며, 현재 공사·통행·입구를 현장에서 확인한 거리는 아닙니다. 점포에서 도로까지의 추정 연결도 총거리에 포함됩니다(E4).
- 새 API·유료 서비스·LIVE 조회·클라우드 검증·배포는 제외했습니다. 새 성능 향상 수치는 측정하지 않았습니다.
