# CU·이마트24 공식 공개 행사 목록 조사

작성일: 2026-11-12. 고정 TEST 자료 제작을 위한 읽기 전용 웹 조사입니다. LIVE 공급자·재고·가격 API를 실행하거나 점포 재고를 확인하지 않았습니다.

## 계획과 방법

상위 `research-plan.md`의 M1에 따라 공식 페이지와 그 화면이 사용하는 공개 요청만 확인했습니다. 인증·로그인·숨겨진 키를 사용하지 않았습니다. CU와 이마트24에서 최대 20회씩 요청하는 한도를 유지하고 충분한 실제 상품명 확보 후 수집을 중단했습니다.

## E-CU-01 — 화면과 요청 계약

- 공식 화면: <https://cu.bgfretail.com/event/plus.do?category=event&depth2=1&sf=N>
- 웹 도구와 직접 GET으로 화면을 확인했습니다. 목록을 `/event/plusAjax.do`에 POST하며 폼의 `pageIndex`, `listType`, `searchCondition`, `category`, `depth2`, `sf`를 전달하는 공개 자바스크립트를 확인했습니다.
- 첫 응답에서 상품 카드 40개와 카드별 상품명, 표시 가격, `plus1`/`plus2`의 행사 배지를 확인했습니다.
- 기본 목록 8페이지에서 CU 1+1 상품 320개를 수집했습니다. 명시적인 `searchCondition=24` 요청 2페이지에서 2+1 상품 80개를 추가했습니다. URL만으로 2+1이라고 간주하지 않고 실제 카드 배지를 사용했습니다.
- 실제 조건과 기간을 알려주는 필드는 확인하지 못했습니다. `start`, `end`, 회원/카드/교차증정 조건을 추정하지 않았습니다. 이미지 파일의 숫자도 공통 바코드로 간주하지 않았습니다.

## E-EM-01 — 화면과 페이지 이동

- 공식 화면: <https://emart24.co.kr/goods/event>
- 화면에 `이달의 행사상품`, 카테고리와 1+1·2+1·3+1·세일·골라담기 필터가 있으며, 페이지 링크의 실제 `page` 매개변수를 확인했습니다.
- 기본 공개 목록 8페이지, 각 20개에서 상품명 160개를 수집했습니다. 행사 배지는 1+1 31개, 2+1 96개, 세일 33개입니다.
- 카드에 원래 가격과 할인 가격이 함께 있으면 `listed_prices`에 둘 다 보존하고 마지막 표시 가격을 `reference_price`로 기록했습니다. 이 값은 해당 점포의 현재 확정 가격이 아닙니다.
- 상품별 시작·종료일, 회원/카드 조건과 교차증정 여부는 확인하지 못했습니다. 현재 달의 첫날/말일을 실제 원본 기간처럼 채우지 않았습니다.

## E-DATA-01 — 저장과 검사

- 산출물: `data/research_cu_emart.json`.
- 총 관측 560개: CU 400개, 이마트24 160개. 응답 18개마다 URL·요청 방법/변수·수신 시각·상태 코드·원문 SHA-256·추출 개수를 저장했습니다.
- 상품별 정확한 원문 이름, 표시 가격/행사, 조회 URL·수신 시각과 핵심 원본 필드를 함께 저장했습니다. 겹치는 관측도 임의로 지우지 않아 후속 동일상품 검토에 사용할 수 있습니다.
- 이름에 적힌 단위만 `volume`으로 추출했습니다. 단위 없는 숫자를 g/ml로 추정하지 않았습니다. 상품명 접두사는 `supplier_label`이며 제조사로 확정하지 않았습니다.
- 모든 관측에서 원본 시각·행사 시작/종료일·제조사가 미제공 상태로 유지되는지 검사했습니다. 이름과 양의 표시 가격이 있는 관측만 저장했습니다.
- 요청 예산: Python 공개 HTTP 요청은 CU 13회(화면/탐색 3 + 수집 10), 이마트24 10회(화면/탐색 2 + 수집 8). 추가 웹 열기 각 1회까지 포함해 각 브랜드 20회 미만입니다.

## 한계와 판단

- 공식 행사 목록의 정적 공개 사실은 확인했습니다. 점포별 취급·실제 재고·실제 가격·현재 영업 상태는 확인하지 않았습니다.
- 페이지 순서상 유제품/음료 등의 비중이 높을 수 있고 전 품목 수집이 아닙니다. 다른 브랜드 관측과 합쳐 300개를 고를 때 다양성을 고려할 수 있습니다.
- 카드에 `1+1`, `2+1`이 있다는 사실만으로 조건이 모두 검증됐다고 할 수 없습니다. TEST에서 동일상품 무조건 증정 규칙을 가정할 경우 원본과 별개의 시뮬레이션 가정으로 기록해야 합니다.
- 제품명·표시 가격·행사 배지를 이용한 현실적인 TEST 씨앗으로 사용할 수 있다는 판단이며, 실제 판매/행사의 전 조건이 확인됐다는 주장은 아닙니다.

## E-FOLLOWUP-01 — 일상 식품 표적 추가 조사

초기 목록이 유제품·음료·생활용품에 치우쳤다는 통합 담당자의 요청에 따라 브랜드별 최대 3회씩 추가 조사했습니다. 초기 관측은 수정하거나 제거하지 않았습니다.

- CU 공개 행사 화면에는 상품 키워드 검색 계약이 확인되지 않아, 지시에 포함된 대체 경로인 2+1 목록 3·4·5페이지를 요청했습니다. 각 40개, 합계 120개를 추가했습니다. 실제 관측에 오뚜기 진짬뽕컵, 농심 튀김우동큰사발컵, CJ 컵반·컵밥·스팸, 동서 리츠크래커 등이 있습니다. 용량이 없는 이름에 용량을 추가하지 않았습니다.
- 이마트24는 공식 화면에서 확인한 `base_category_seq=2`(과자) 목록에서 20개를 추가했고, 공개 `search=라면`에서 24개, `search=샘물`에서 12개를 추가했습니다. 동원·풀무원 샘물 500ml/2L 및 묶음 상품이 포함되며 서로 다른 포장 단위를 그대로 보존했습니다.
- `source_category=과자`는 실제 이마트24 과자 필터로 받은 20개에만 부여했습니다. 나머지 상품의 분류는 임의로 채우지 않았습니다.
- 최종 누적: **관측 736개, 원문 상품명 726개, 응답 출처 기록 24개**. 추가 수집 뒤에도 행사 시작/종료일·원본 갱신 시각 미제공 상태를 보존했는지 검사했습니다.
- 이 하위 작업의 Python 공개 HTTP 요청 누계는 CU 16회, 이마트24 13회입니다. 웹 열기 각 1회와 통합 담당자의 별도 CU 웹 열기 1회를 합쳐도 CU 18회, 이마트24 14회로 브랜드별 20회 한도 이내입니다. 더 이상 요청하지 않았습니다.
