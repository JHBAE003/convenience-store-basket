# v2.1 화면 개선 기준

주 사용자: 컴퓨팅 실습 과제를 시연하거나 편의점 상품을 비교하려는 한국어 사용자.
주 작업: 상품을 사진과 규격으로 찾아 담고, 선택한 상품의 매장별 수량·결제액을 확인한다.

Design Partner 플러그인의 refine/surface 기준을 적용한다. 수집 개선과 관계없는 탐색 구조 변경이나 대규모 재작성은 하지 않는다.

## 직접 참고한 공개 웹페이지

- [컬리 상품 목록](https://www.kurly.com/main): 검색과 필터, 상품 사진·이름·가격·담기 버튼을 같은 흐름으로 읽는 구성. 사진과 가격을 주된 정보로 두고 보조 문구의 강조를 낮추는 방식을 참고했다. 할인율·회원가 등의 실제 내용이나 이미지·상표 디자인은 가져오지 않았다.
- [GS25 공식 소개](https://www.gsretail.com/brand/gs25): 제목으로 기능을 구분하고 매장 찾기를 별도 행동으로 두는 구성. 상품 찾기와 매장 비교를 구분하는 데 참고했다. 큰 광고 배너는 현재 앱의 작업과 관계없어 추가하지 않았다.

## 적용

- 한국어 제목·행동 안내와 초록색 주요 버튼, 흰색 상품 카드, 중립색 설정 영역을 유지하며 간격·테두리·제목 크기를 정리한다.
- 좌표는 펼쳐서 입력하고, 일반 사용자는 주소·브랜드·반경·예산을 먼저 본다.
- 후보 목록의 가격은 참고가, 선택 상품의 매장 재고는 비교 시 확인으로 설명한다.
- 확인 범위를 결과 앞에 표시하고, 상세에서 앱 수신 시각·원본 자료 시각·저장 자료 사용을 구분한다.
- 원본 자료 시각을 제공받지 못했으면 미제공이라고 표시한다.
- 한국어 상태와 복구 안내를 제공하고 일반 흐름에 원시 오류·수집 도구 이름을 나열하지 않는다.
- Streamlit 기본 버튼·입력·펼침 요소를 재사용해 키보드 조작을 보존한다. 고정 높이·숨긴 스크롤·광고 장식·새 UI 의존성을 추가하지 않는다.

실제 화면 점검 결과는 `docs/v2.1-verification.md`에 기록한다.
