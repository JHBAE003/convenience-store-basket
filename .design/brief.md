# 편의점 장바구니 화면 정리

- 모드: Design Partner redesign. 2026-11-05 사용자 요청에 따라 기존 v3.1.1을 수정한다.
- 사용자의 일: 상품을 찾아 담고 가격·이동 거리·방문 수·예산을 비교해 구매안을 선택한다.
- 구성: 넓은 화면은 상품 목록/추천과 장바구니를 나란히 둔다. 900px 이하는 상품 찾기·장바구니·추천·경로를 전환한다. 장바구니와 각 화면 선택은 모두 유지한다.
- 스타일: 옅은 녹색 바탕, 흰 상품 면, 짙은 녹색 주요 동작, 짧은 한국어 문구, 일관된 작은 제목·수치·간격. Streamlit 기본 컨트롤과 로컬 CSS를 사용한다.
- 참고: https://www.kurly.com/main 의 검색·상품 이미지·가격·담기 구성, https://www.apple.com/kr/maps/ 의 주요 경로와 보조 정보 위계. 홍보 배너나 원본 디자인/자산을 복제하지 않는다.
- 유지: TEST/LIVE 분리, TEST 가상 표시, 상품 그림이 실제 포장이 아니라는 안내, 가격·재고 미확인 구분, 자료 시각, 브랜드별 검색·요약, 장바구니·계산·도보 지도·저장.
- 제외: 유료 API, LIVE 실행/검증, GitHub 업로드, 배포. 엔진·데이터셋·이전 버전은 보존한다.
- 이동: SQLite·DP·캐시 구현 설명은 README에만 둔다. 확인 시각·출처·비교표·조회 옵션은 접힌 보조 영역에 둔다. 실제 오류와 복구 안내는 숨기지 않는다.
- 검증: TEST 전용 자동 검사와 브라우저의 넓은/중간/320px 화면, 키보드 검색/탭 이동, 초점 표시, 수량/삭제/비교/빈 결과/조회 필요 상태. 스크린리더나 실제 LIVE 검증은 별도 범위다.
