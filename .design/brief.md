# 편의점 장바구니 v3.2.1 디자인 기준

- 작성일: 2026-11-12. 기존 v3.2.0을 보존하고 새 v3.2.1 폴더에서 개선한다.
- 목적: 상품을 찾아 담고, 결제액·이동 거리·방문 수·예산을 비교해 구매안을 고른다. 화면은 상품 탐색과 구매 결정에 집중한다.
- 구성: 1280px 초과 화면은 상품 목록/추천과 장바구니를 2:1 비율로 둔다. 기존 상품 찾기·장바구니·추천·경로 전환과 선택 상태를 유지한다. 1280px 이하에서는 장바구니 전용 화면을 사용하고, 탐색·추천 화면에 상품 수와 장바구니 이동·구매안 비교 버튼을 표시한다. 사이드바가 열린 중간 폭에서 수량·삭제 컨트롤의 공간을 확보하기 위한 전환점이다.
- 시각 방향: 따뜻한 중립색 바탕(#F6F5F1), 흰 상품 면, 짙은 청록색 주요 동작(#17635B), 짙은 본문(#203935), 보조 글자(#566860). 과장된 홍보 문구·장식·외부 폰트 의존성을 추가하지 않는다.
- 상품 화면: 구분용 그림을 112px로 줄이고 카드 간격·높이를 정리한다. 상품 이름 입력란의 보이는 이름과 짧은 예시를 제공한다. 참고가는 점포의 확정 판매가와 구분한다. 기존 갤러리 페이지와 브랜드별 전체 검색 결과를 유지한다.
- 추천 화면: 결제액·이동 거리·방문 매장 수를 반응형 수치 영역에 놓고, 방문 경로와 매장별 구매 목록으로 이어지게 한다. 도보 지도에서 점선은 추정 진입 구간이라는 설명을 유지한다.
- 구현 방식: Streamlit 기본 입력·탐색·버튼·수치·접기 요소를 사용한다. 색상·글자·모서리는 기본 테마 설정을 우선하며, 로컬 CSS는 이름이 지정된 상품·장바구니 영역의 배치·모바일 표시·초점 표시 등에 제한한다. 별도 UI 프레임워크를 추가하지 않는다.
- 도구: Design Partner와 설치된 Streamlit 참조 문서를 활용한다. Figma 도구는 확인했으나 대상 디자인 파일이 제공되지 않아 이번 검토에서 원격 디자인 파일을 만들거나 캡처하지 않았다. Figma 산출물을 구현 근거로 주장하지 않는다.
- 유지 조건: TEST/LIVE 분리, TEST 가상 표시, 그림의 구분용 성격, 가격·재고 미확인 구분, 원본/수신 자료 시각, 브랜드별 검색·요약, 장바구니·계산·도보 지도·저장. 데이터셋·공급자·계산 결과·이전 버전은 보존한다.
- 보조 정보: 자료 시각·출처·비교표·조회 옵션은 접힌 영역에 둔다. 실제 오류와 복구 안내는 숨기지 않는다. SQLite·알고리즘·캐시 구현 설명은 개발 문서에 둔다.
- 검토 범위: 이 파일을 갱신한 검토자는 코드 차이·CSS·테마와 정적 색상 대비만 확인했다. 본문/바탕 11.34:1, 보조 글자/흰 면 5.92:1, 보조 글자/사이드바 5.13:1, 흰 글자/청록 7.07:1이다. 실제 렌더링의 모든 상태·입력 경계·키보드·스크린리더 검증을 의미하지 않는다.
- 화면 확인 항목: 넓은/중간/320px 폭과 200% 확대, 사이드바가 열린 중간 폭에서 장바구니 수량·삭제 버튼의 줄바꿈, 모바일 비교 버튼, 키보드 초점, 검색·수량·삭제·비교·빈 결과·조회 필요 상태. 실행한 검사는 별도 검증 보고서에 기록한다.
- 제외: LIVE 실행·전환·모의 LIVE 검증, 유료 API, GitHub 업로드, 배포. 이번 디자인 기록만으로 해당 작업의 성공을 주장하지 않는다.
