# 가상 상품 그림

이 프로젝트에서 직접 만든 상품 구분용 SVG 그림입니다. 실제 브랜드 로고·포장 사진을 사용하지 않았습니다. 300종 각각에 분류별 형태, 맛을 구분하는 색, 용량·포장 수·TEST 상품 코드를 표시합니다. 모양과 색이 같은 경우도 있으므로 상품명과 규격을 함께 확인합니다.

`python scripts/build_product_icons.py`로 동일한 SQLite 자료에서 결정적으로 다시 생성합니다. 인터넷, 외부 폰트, 이미지 API가 필요하지 않습니다. 외부 실제 상품에는 대응하는 사진인 것처럼 표시하지 않고 공통 그림만 사용합니다.
